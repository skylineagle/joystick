# WiFi Access Point Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add WiFi AP management as a device capability for Teltonika RUT950/956, with RUT HTTP API utils in core, dedicated joystick endpoints, a new `joystick` run target type, dev-tools mock + seed, and a full frontend page.

**Architecture:** Devices advertise WiFi AP support via PocketBase `run` rows with `target: "joystick"` and `command: "METHOD /path"`. The joystick run handler self-fetches dedicated WiFi AP endpoints which call `rut.utils.ts` in core to hit the Teltonika REST API. The frontend polls these endpoints for a live dashboard.

**Tech Stack:** Bun, Elysia, PocketBase, TypeScript, React, TailwindCSS, @tanstack/react-query
